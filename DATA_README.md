# Data folder

This project keeps its raw data in dedicated folders so code stays separate from the dataset.

- `50kReviews/` holds review text data.
- `imdbMetadata/` holds IMDb metadata used to enrich movie information.
- `movielensRatings/` holds MovieLens rating data used for collaborative filtering.

Keep raw dataset files in these folders and keep code in the Python files at the project root.
